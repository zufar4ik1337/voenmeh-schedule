# Расписание Военмеха — сайт

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | Сам сайт: поиск по группам и преподавателям, расписание на сегодня, завтра и неделю, кнопка «В календарь» |
| `manifest.webmanifest`, `sw.js`, `icons/` | Установка как приложение (PWA) и работа без интернета |
| `privacy.html` | Политика конфиденциальности |
| `data/schedule.js` | Расписание всех групп, собранное из XML вуза |
| `update_schedule.py` | Скрипт: скачивает свежий XML с voenmeh.ru, собирает `data/schedule.js` и календари для подписки `ics/` |
| `data/source.xml` | Последняя скачанная копия XML (запасная, если сайт вуза недоступен) |
| `github-actions-deploy.yml` | Автообновление раз в неделю и выкладка на GitHub Pages. На GitHub он должен лежать по пути `.github/workflows/deploy.yml` |

## Как посмотреть сайт

Открой `index.html` двойным кликом, и он откроется в браузере. Сервер не нужен.

## Как обновить расписание

Нужен Python 3.9+ (python.org, при установке поставь галочку «Add to PATH»).

```
cd путь\к\папке\voenmeh-schedule
python update_schedule.py
```

Если скачать не получается, сохрани XML вручную и передай его скрипту:

```
python update_schedule.py TimetableGroup50.xml
```

XML: https://voenmeh.ru/wp-content/themes/Avada-Child-Theme-Voenmeh/_voenmeh_grafics/TimetableGroup50.xml

## Настройки (в начале update_schedule.py)

- `LESSON_MIN = 90` — длительность пары в минутах.
- `SEMESTER_END = "2026-12-27"` — последний день занятий: до него пары повторяются в календаре.

## Как работает чётность недели

Логика та же, что на сайте вуза. Неделя, в которую начинается семестр (`Period` в XML), нечётная, дальше недели чередуются.

## Подписка на календарь

Кнопка «📅 В календарь» даёт постоянную ссылку вида `сайт/ics/g/3032.ics`.
Телефон раз в несколько часов сам перечитывает этот файл, а GitHub Actions
раз в неделю пересобирает его из свежего XML. Поэтому изменения в расписании
доходят до календаря без участия студента.

Пока сайт открыт с компьютера (файлом), доступно только скачивание `.ics`.

## Счётчик посещений

Используется Яндекс Метрика (бесплатно). Создай счётчик на metrika.yandex.ru,
укажи адрес сайта и впиши номер счётчика в `METRIKA_ID` в начале скрипта в `index.html`.
Цели, которые отправляет сайт: `open_group`, `open_lecturer`, `calendar_subscribe`, `calendar_file`, `calendar_copy`.
Пока сайт открыт файлом с компьютера, счётчик не работает.
